## 宇宙云支持通用订阅吗？ClashMi怎么导入？

**支持通用订阅链接。** 套餐说明明确写有订阅链接支持，帮助中心也提供ClashMi添加配置链接的教程。本次控制台没有找到实际复制订阅链接的按钮，个人订阅的领取位置还需要在账户内或向客服确认。

iOS上的ClashMi手动导入流程如下：

1. 使用外区Apple ID下载安装ClashMi。
2. 获取自己账户的宇宙云订阅链接。
3. 打开ClashMi，进入“我的配置”，点击“+”。
4. 选择“添加配置链接”，粘贴个人订阅链接并保存。
5. 选择配置，按客户端提示完成连接。

这是手动添加配置链接的流程，不能写成后台支持一键导入。其他客户端及软路由是否兼容，还应确认订阅格式和具体配置方式。
