## 客户端与通用订阅

| 设备 | 官网说明 |
|---|---|
| Windows | 官方客户端，登录账号后连接 |
| Android | 官方客户端，登录账号后连接 |

| iPhone / iPad | 官方文档明确不支持官方客户端，需使用Shadowrocket等第三方客户端 |

仪表盘提供复制订阅、二维码，以及Clash、Surge、Shadowrocket、Surfboard、Quantumult X订阅入口，属于支持通用订阅的服务。不同入口并不意味着每个平台都经本站实测。

### 使用流程

1. 从上方官网入口注册或登录，确认套餐流量、连接设备数量和价格。
2. 电脑、安卓及Linux用户可进入使用文档下载官方客户端，登录后连接。
3. iPhone/iPad用户按官网教程安装第三方客户端，从仪表盘导入对应订阅。
4. 首次导入后更新节点，选择常用地区并测试网页、视频等实际用途。
5. 节点超时或订阅更新失败时，套餐页建议登录网站重新导入或联系售后；也可参考[订阅故障排查](/posts/clash-subscription-troubleshooting/)。

## 适合什么使用场景

- **单设备轻度使用：** 9.9元80GB入门档，但仅允许1台设备与IP同时连接。
- **多设备使用：** 按2台、3台或5台限制选择相应套餐，不能仅按流量比较。
- **低频备用：** 可比较50元100GB或199元500GB不限时包。
- **较大流量需求：** 可比较36元500GB与49元不限流量，后者仅标注2台并发，公平使用政策待核实。

套餐宣传BGP＋IEPL中转以及Netflix、Disney+、ChatGPT解锁，属于商家说明，实际效果与节点、网络及平台策略有关。

### 最低月付多少钱？
