## 客户端与使用流程

| 设备 | 本次官方教程 |
|---|---|
| Windows | v2rayN，添加订阅组后更新订阅 |
| macOS | v2rayN，区分Intel与Apple芯片安装包 |
| Apple芯片Mac | Mac教程另提到可使用iOS版Shadowrocket |
| Android | Flyer，支持一键导入或手动复制订阅 |
| iPhone / iPad | 官网提供iOS教程入口，具体步骤以后台文档为准 |

本次读取的教程均为第三方客户端路线，未见自有专属客户端说明。Android教程写明手动导入时在Flyer内选择FLCLASH格式，不等于所有Clash客户端均已测试通过。

1. 从上方官网入口登录，先确认所需流量、有效期及限速。
2. 按官网说明充值账户余额，再在套餐页订购，购买后即刻生效。
3. 打开设备对应教程，安装客户端并复制或一键导入订阅。
4. 更新节点，选择可用节点并启用代理，验证常用网站。
5. 连接异常时先检查订阅状态、余额和流量，再更新订阅、切换网络或联系客服；也可查看[订阅故障排查](/posts/clash-subscription-troubleshooting/)。

## 计费倍率、试用与退款

FAQ说明：节点名称未标注倍率时按1倍率计费，即使用1GB扣1GB；标注1.5x时，使用1GB扣1.5GB。

“入门试用”需要支付7元，并非免费体验。仪表盘有签到入口，但本次未核实新用户免费流量的领取条件、额度及有效期，因此免费试用待核实。退款、充值退回、套餐叠加及长周期流量重置规则也未在所读说明中明确。

## 适合哪些使用场景

- **轻量短期使用：** 可比较7元50GB，但须接受200Mbps标称上限及不含专线。
- **需要IEPL选项：** 从30元500GB档起比较，结合自己的设备与网络验证。
- **较长周期使用：** 先确认90天、180天套餐的流量发放和重置方式，再决定是否购买。
- **低频备用：** 不限时入门需365元，购买门槛与旧资料中的50元明显不同。

## 常见问题

### 最低还是5元80GB吗？

不是，本次套餐页最低为7元/30天50GB。

### 入门试用免费吗？

不是，是7元的付费套餐；免费体验规则尚未确认。

### 所有套餐都有IEPL吗？

不是，7元、10元和15元档均注明不支持专线，30元档起标注支持IEPL。

### 可以多设备使用吗？

套餐页均标注设备数不限，实际流量消耗和使用规则仍按套餐及节点倍率计算。
