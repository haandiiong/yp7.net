| 设备 | 本次官网可见入口与教程 |

3. Android按设备架构选择安装包；Windows按教程安装自研客户端并用注册邮箱账号登录；macOS按对应教程操作。
4. iPhone或iPad用户按官网教程下载Nextin，填写服务识别码`1fly0404`后登录账号。该识别码用于识别服务，不是购买优惠码。

## ChatGPT与流媒体怎样确认？

官网套餐卡片有AI和流媒体解锁的介绍。判断能否满足自己的需求，应检查具体节点、地区与应用，而不是只看节点数量或速度截图。

| 使用场景 | 实际使用时应检查的内容 |
|---|---|
| ChatGPT | 常用节点能否登录、开始并持续完成对话 |
| YouTube | 常用清晰度下的加载、缓冲和播放情况 |
| Netflix / Disney+ | 目标地区片库、账号登录及实际播放情况 |
| 日常网页和消息 | 页面打开、消息同步、图片与文件加载情况 |

记录结果时应保留日期、节点地区、运营商与客户端环境。不同地区和时段的结果可能不同，商家解锁说明与历史测速图都不能替代这些实际使用结果。
