软路由是用通用计算硬件和路由软件提供网络功能的一种实现方式。它可以做主路由、二级路由或旁路由；“软路由”与“旁路由”不是互相排斥的设备类别。

是否需要软路由，要看现有设备能否满足需求，以及你是否愿意维护系统、网络和备份。设备多、需要统一分流，并不意味着换成软路由就一定更快或更稳定。

## 一、软路由是什么？（核心原理）

常见组合是迷你主机、旧电脑或受支持的ARM设备，运行OpenWrt等路由系统，再按需配置DHCP、DNS、防火墙、VPN或代理插件。它不限定为x86，也不必安装代理插件才算软路由。

硬件、系统和部署角色可以分别选择。例如，同一台双网口迷你主机既能直接连接宽带承担主路由，也能接在现有主路由后面，为一组设备提供二级路由服务。

## 二、软路由和普通路由器的区别

| 对比维度 | 常见消费级路由器 | 通用硬件软路由 |
|---|---|---|
| 硬件 | 通常集成无线、交换与路由功能 | 按需求选择网卡、存储与内存；无线可能需要独立AP |
| 系统维护 | 依赖厂商固件与支持周期；部分支持开放固件 | 由用户维护系统、软件包及升级兼容性 |
| 扩展能力 | 因型号和固件而异 | 可添加系统支持的软件，但需自行管理冲突 |
| 性能 | 受硬件及硬件加速影响 | 受CPU、网卡、驱动、协议和软件转发路径影响 |
| 成本 | 采购后通常配置较少 | 还需考虑功耗、网卡、AP和维护时间 |

不能把普通路由器一概描述为封闭、低性能，也不能认为软路由一定更强。先列出需要的功能，再核对具体设备。

## 三、哪些人适合用软路由？（用户画像）

有以下明确需求时，可以评估软路由：

- 管理多网段、访客网络、DNS或网络访问策略。
- 为不便安装客户端的设备提供统一VPN或代理入口。
- 记录和排查网络连接，愿意学习地址、DHCP、防火墙及备份。
- 现有路由器缺少所需功能，而已有可复用的受支持设备。

如果只是手机或电脑需要一个客户端，先使用该设备上的软件通常更容易维护。不会因为安装软路由就自动获得机场节点、流媒体权限或更低的游戏延迟。

## 四、主流软路由系统选择（2026） {#四、主流软路由系统推荐-2026}

### OpenWrt

OpenWrt是可运行在多种受支持设备上的开源路由系统，可通过LuCI管理接口、DHCP/DNS及防火墙。VPN和代理功能需要安装对应组件，并取得兼容配置。安装前查询[官方设备列表](https://openwrt.org/toh/start)，不要只按CPU架构下载一个镜像。

OpenWrt 25.12系列使用APK包管理器，旧24.10系列使用opkg；命令和包格式不同。对版本与依赖的选择，应参考[官方版本说明](https://openwrt.org/releases/25.12/notes-25.12.0)与插件维护者说明。

### 爱快（iKuai）

爱快是另一类路由系统选择。是否满足多WAN、流量管理或所需VPN功能，应在[爱快官网](https://www.ikuai8.com/)核对版本文档、硬件要求与功能限制，不以界面简洁推断它适合所有新手。OpenWrt插件和教程不能直接套用于爱快。

本文的具体配置示例采用OpenWrt，没有对两个系统进行本站性能或稳定性比较。

## 五、软路由硬件选择

先确定宽带接入、目标协议和部署角色，再决定硬件：

| 需要核对 | 为什么 |
|---|---|
| 网口数量和驱动支持 | 本站二级路由示例需要两个独立接口；单网口方案涉及VLAN、USB网卡或不同拓扑 |
| CPU和目标协议 | 不同加密协议、连接数和规则会改变负载，型号或频率不能保证跑满宽带 |
| 内存和可用存储 | 插件、内核、规则和日志需要余量；不要在空间不足时继续安装 |
| 无线需求 | 多数迷你主机不能替代成熟无线AP，需要另配接入点 |
| 散热、功耗与维护 | 长期开机要观察温度和实际功耗，并安排备份及升级 |
| 安装与恢复支持 | 固件镜像、网卡、启动方式、显示/串口恢复能力都需匹配设备 |

不按“N100必满千兆”“树莓派一定性能不足”这样的结论购买。树莓派或其他ARM设备是否适用，取决于型号、网口和具体负载。没有同协议、同网络的测试记录时，不提供带宽保证。

## 六、OpenWrt安装教程（新手流程）

### 安装前先确认镜像和写入对象

1. 查询完整设备型号、硬件版本、网卡及启动方式，在[官方固件选择器](https://firmware-selector.openwrt.org/)找对应镜像。
2. 按设备页安装说明区分首次安装、升级和恢复文件。x86磁盘镜像、厂商路由器factory镜像及sysupgrade文件不能互换。
3. 备份现有系统和数据，准备恢复介质；向磁盘或存储卡写入镜像会覆盖所选目标，确认不是电脑的资料盘。
4. 首次启动时用有线电脑单独接设备，按设备说明识别LAN口和管理地址。`192.168.1.1`是常见初始LAN地址，定制镜像或已有配置可能不同。
5. 设置管理员密码、确认时间及接口，再保存[配置备份](https://openwrt.org/docs/guide-user/troubleshooting/backup_restore)。系统配置备份不包含所有插件二进制文件，不等于完整磁盘备份。

x86设备的镜像类型、EFI启动和写盘步骤以[OpenWrt官方x86说明](https://openwrt.org/docs/guide-user/installation/openwrt_x86)为准。先把OpenWrt网络配置好，再安装代理插件，避免同时更改固件、网段和订阅后无法定位问题。

## 七、软路由科学上网配置（核心玩法）

OpenClash是第三方维护的OpenWrt插件，用于管理Clash/Mihomo兼容配置。它与VPN服务器、OpenVPN客户端、WireGuard客户端是不同组件；下载插件不会自动提供可用订阅。

详细流程见[OpenWrt与OpenClash二级路由配置教程](/posts/router-vpn-setup-2026/#七、路由器翻墙配置教程)。该教程固定一个可理解的示例：

- 现有主路由保持`192.168.1.1/24`，原Wi-Fi和设备继续使用。
- 主路由LAN接OpenWrt WAN，WAN使用DHCP取得上游地址与默认路由。
- OpenWrt LAN使用另一网段`192.168.20.1/24`，向下游设备提供DHCP和DNS。
- 先确认基础直连，再安装OpenClash、导入兼容订阅并查看分流连接。
- 出错时把测试设备接回原主路由，恢复自动IP和DNS即可先恢复原连接。

这不是同网段旁路由方案。照搬他人的网关或DNS地址可能形成路由环路；无论用哪种方案，都应先画出设备到互联网的路径。

## 八、软路由常见应用场景

| 场景 | 需要实际验证 |
|---|---|
| 多设备统一分流 | 每台设备是否处于目标网段、使用正确网关和DNS |
| DNS过滤或广告过滤 | 设备自带DoH/私人DNS是否绕过路由器，是否与现有插件冲突 |
| 多网段或访客隔离 | 防火墙转发、管理访问和跨网段发现是否符合预期 |
| 电视、游戏或流媒体 | NAT、UDP、节点、应用地区及账户功能是否正常 |
| 作为旁路由 | DHCP来源、客户端网关、回程路由及IPv6路径是否一致 |

这些是可配置的场景，不是每一台软路由默认具备或能保证完成的功能。

## 九、软路由 vs 旁路由（重要区别）

**软路由是实现方式，主路由、二级路由和旁路由是部署角色。** 同一台软路由可以承担不同角色，普通路由器在支持相关配置时也可能作旁路由。

| 概念 | 表示什么 | 常见职责 |
|---|---|---|
| 软路由 | 用通用硬件和路由软件实现网络功能 | 角色由接线、接口、路由和防火墙配置决定 |
| 主路由 | 网络的主要出口角色 | 连接上游、拨号或取得地址，通常提供DHCP、DNS和NAT |
| 二级路由 | 接在现有路由器后，管理另一网段 | WAN连接主路由，LAN服务下游；常有双重NAT |
| 同网段旁路由 | 额外网关或服务设备 | 指定设备把网关/DNS指向它，或由主路由配合转发 |

不能把旁路由理解为不需要配置的“外挂加速器”。如果客户端默认网关仍指向主路由、路由规则也没有转向旁路由，通常不会因为旁边多了一台设备就自动走代理。

## 十、常见问题 FAQ

### Q1：软路由难吗？

需要理解IP、网关、DHCP、DNS及防火墙。准备时间受硬件和固件影响，不承诺一小时完成。先用一台测试设备验证，再扩大到全家。

### Q2：功耗高吗？

取决于平台、网卡、负载和电源效率，最好用功率计观察。月用电量可按“平均功率W÷1000×每天小时数×天数”估算，再乘当地电价；不为所有设备给一个固定电费。

### Q3：软路由稳定吗？

稳定性取决于硬件、驱动、系统版本及配置。可扩展功能也增加维护成本，不能单凭软路由类别认定比普通路由器稳定。

### Q4：需要公网IP吗？

普通出站访问通常不需要公网IP；从外部直接访问家庭服务则需要另行考虑公网可达性、端口和防火墙，不属于本文的出站代理示例。

### Q5：能跑满千兆吗？

需要在实际协议、规则、连接数和网络下测量。网口标称1Gbps并不等于代理有效吞吐为1Gbps。

### Q6：电费多少？

例如平均10W、每天24小时、30天，约消耗7.2kWh。实际费用取决于测得的功率和当地电价；这只是计算示例，不是某个型号的实测。

### Q7：至少需要几个网口？

本文二级路由示例需要两个独立接口。单网口可通过VLAN等方式部署，但增加配置要求；不能认为任何角色都必须两个或四个网口。

## 十一、软路由优缺点总结

优势是可按需求组织硬件、网络和软件，便于扩展与排查。代价是系统升级、插件依赖、散热、功耗和备份需要用户自己管理；无线覆盖通常还需独立AP。

## 十二、总结：软路由值不值得买？

先列出一个当前路由器做不到的明确需求，再核对软路由能否解决。如果客户端已满足日常使用，没有必要只为“更快更稳”的笼统承诺购置设备。准备部署时，保留原网络作为回滚路径，验证功能后再考虑长期使用。
