## 本站现在负责什么

yp7.net 从此只做机场推荐与信息整理，主要负责：

- 汇总套餐价格、流量、试用、不限时规则、客户端和通用订阅支持情况。
- 按新手、低价、Clash、ChatGPT、流媒体等使用场景整理候选。
- 提醒官网异常、客服失联、退款、支付、长期续费和套餐变更风险。
- 说明推广链接、排序原则、更新时间和历史资料状态。

yp7.net 不再把自己描述为当前测试方，也不再新增本项目自产的测速数据。读者仍可以按照教程在自己的设备和网络环境中测试；这属于个人验证，不代表 yp7.net 发布新的实测结论。

## 数据来源与职责边界

| 信息类型 | 当前来源 | yp7.net 如何使用 |
|---|---|---|
| 速度、延迟、稳定性、ChatGPT、流媒体等测试数据 | [Siilas 测速中心](https://siilas.com/test/) | 引用并用于推荐参考，明确标注来源和时效 |
| 2026年8月18日前的本站测速截图与测试记录 | yp7.net 历史页面 | 仅作历史资料，不用于证明当前表现 |
| 套餐、价格、流量、试用、客户端和退款规则 | 服务商官网与后台 | 整理、核对并提示可能变化 |
| 官网异常、客服、付款与续费风险 | 公开信息、服务商状态和读者反馈 | 整理风险提示；个别反馈需要复核 |
| 最终可用性 | 读者自己的设备、地区、运营商和时段 | 建议试用或月付后自行验证 |

如果 Siilas、服务商官网、本站历史记录和用户本地体验之间存在差异，应优先看信息日期和来源：当前测试以 Siilas 为准，套餐规则以服务商官网后台为准，最终购买决定以用户自己的短期验证和风险承受能力为准。

## 推荐维度

机场推荐页不按单次测速或最低价格机械排序。yp7.net 结合以下信息做推荐：

| 推荐维度 | 参考内容 | 说明 |
|---|---|---|
| 当前测试表现 | Siilas 的速度、稳定性与应用记录 | 数据会随时间和网络环境变化 |
| 新手易用性 | 专属客户端、订阅导入、教程和节点切换 | 决定上手成本 |
| 场景匹配 | Clash、ChatGPT、流媒体、办公和低价备用 | 只表示推荐方向，不承诺长期可用 |
| 价格与套餐 | 月付、流量、试用、不限时规则 | 以服务商后台为准 |
| 风险 | 官网、客服、退款、支付、历史异常 | 决定是否适合购买或续费 |

推荐顺序是编辑判断，不等于测试排名。推广佣金不会自动提高推荐位置，带推广参数的入口会在构建时标记为 `rel="sponsored nofollow noopener noreferrer"`。

## 历史测试记录处理规则

2026年8月18日前已发布的测速截图、延迟、下载速度、晚高峰、YouTube、ChatGPT 和流媒体记录不会删除，但必须按以下规则展示：

1. 明确标记为“历史测试记录”或“历史截图”。
2. 保留原测试日期、设备和网络环境，避免脱离上下文使用。
3. 不在当前结构化服务字段中把历史速度描述成实时表现。
4. 没有历史记录的机场不再写“待 yp7.net 复测”，而是引导至 Siilas 查看当前记录。
5. 推荐可以更新，但不能用旧测速值证明当前速度或稳定性。

## 购买前核对流程

1. 在 [机场推荐主页面](/posts/jichang-tuijian/) 按预算、客户端和使用场景缩小范围。
2. 前往 [Siilas 测速中心](https://siilas.com/test/) 查看对应服务的最新测试时间、记录与缺失项。
3. 在服务商官网后台核对价格、流量、试用、客户端、退款和支付规则。
4. 查看 [机场风险监测](/risk-monitor/) 中的官网异常、客服失联、套餐变化和停止推荐记录。
5. 优先使用试用、月付或短周期套餐，在自己的设备、地区、运营商和常用时段验证。
6. 只有在可用性和风险都可接受时，再考虑续费；不建议第一次购买就直接年付。

本站不承诺任何机场永久可用、绝对安全或固定解锁。机场服务会受线路维护、节点负载、平台策略和服务商运营影响。涉及付款、USDT、交易所、账号注册和跨境网络访问时，请自行确认当地规则、服务条款、资金风险和账号安全要求。

## 常见问题

### yp7.net 现在还做测速吗？

不做。自 2026年8月18日起，yp7.net 不再自行开展或发布新的测速与实测。

### 当前测速和测试结果去哪里看？

统一查看 [Siilas 测速中心](https://siilas.com/test/)。yp7.net 在推荐中使用相关数据时会标明来源。

### 旧测速截图为什么没有删除？

旧记录可以帮助读者了解当时的测试环境和内容变化，因此作为历史资料保留，但不能用来证明当前表现。

### yp7.net 以后更新什么？

继续更新机场推荐、套餐与客户端信息、场景匹配、风险提示、商业披露和教程，不再新增自产测试数据。

### 为什么仍建议用户自己测试？

Siilas 和任何第三方记录都无法完全替代用户所在地区、运营商、设备和常用时段的实际体验。自行短期验证是购买决策的一部分，但不属于 yp7.net 的项目测试。
