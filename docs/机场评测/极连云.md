## 客户端与订阅方式

仪表盘有Android、iOS、macOS、Windows下载区；知识库另有Linux和软路由分类。Windows教程明确提供极连云客户端，使用注册邮箱登录，更新节点、测试延迟后连接。

极连云**不支持通用订阅**，该规则由站长于2026年9月27日补充确认。使用时按官网对应设备的客户端教程连接；仪表盘的第三方软件推荐文字不代表提供可导入的通用订阅。

1. 从上方官网入口登录，选择合适套餐。
2. 查看系统对应知识库教程，下载客户端并登录。
3. 更新节点、测试延迟，选择节点并连接。
4. 连接后检查常用网站和应用，并留意流量余额及套餐有效期。
