## 🧠 什么是Clash节点？

**Clash节点**就是可以访问国外网络的“跳板”。  
通过节点，你的网络请求可以绕过限制，访问被封锁的网站或流媒体。

### 节点工作原理

1. **本地设备 → Clash客户端**  
   Clash在本地充当代理，接收请求。

2. **Clash客户端 → 节点服务器**  
   节点位于海外，访问目标网站。

3. **节点服务器 → 本地设备**  
   返回网站内容，实现加速和解锁限制。

> 💡 小贴士：选择稳定节点可以减少延迟和掉线问题。

## 📊 Clash节点协议分类

| 协议 | 说明 | 使用时核对 |
|------|------|------|
| **VMess** | 一种代理协议 | 客户端内核是否支持配置中的传输方式 |
| **Shadowsocks / ShadowsocksR** | 不同的代理类型 | 订阅中的类型与加密方式是否受支持 |
| **Trojan** | 使用 TLS 的代理协议 | 服务器、端口和 TLS 配置是否完整 |
| **Snell / SOCKS5** | 不同的代理类型 | 按服务商说明导入，不能互换类型名称 |

客户端支持的协议取决于所带内核与版本。新手优先使用服务商提供的兼容订阅，不必先手动改协议；协议名称本身不能证明速度或稳定性。[Mihomo 出站代理文档](https://wiki.metacubex.one/config/proxies/)

## 🚀 新手如何使用Clash节点

### 1️⃣ 下载Clash客户端

- **Windows / macOS / Linux**：[Clash Verge Rev 教程](/posts/clash-verge-guide-2026/) / [FlClash 教程](/posts/flclash-guide-2026/)
- **Android**：FlClash / [Clash Meta 教程](/posts/clash-for-android-guide-2026/)
- **iOS**：先查看 [iPhone 客户端安装说明](/posts/shadowrocket-guide-2026/)，再核对所选应用的订阅格式；不要直接套用桌面版 Clash 的菜单与配置步骤。

### 2️⃣ 获取节点订阅

- 提供兼容订阅的机场（例如：[Flybit](/posts/flybit-review-2026/) / [网际快车](/posts/wangji-kuaiche-review/) / [99吧](/posts/99ba-review-2026/)）。xxyun 仅支持官方客户端，不能用于本节的订阅导入流程。

### 3️⃣ 导入节点

1. 打开Clash客户端  
2. 进入 **配置文件/Config**  
3. 选择 **导入远程订阅** 或 **本地导入**  
4. 粘贴订阅链接或选择配置文件  
5. 点击 **应用/启用**

### 4️⃣ 选择代理策略

- **Global（全局模式）**：进入内核的流量使用全局策略组，需先在该组选择节点
- **Rule（规则模式）**：按当前配置的规则决定流量去向
- **Direct（直连模式）**：进入内核的流量直接连接

> 日常可从 **Rule 模式**开始，但实际分流取决于订阅中的规则。模式选择与系统代理、VPN 或 TUN 的开启是不同设置。[Mihomo 运行模式说明](https://wiki.metacubex.one/config/general/#运行模式)

### 5️⃣ 测试节点速度

- 点击 **测速 / Speed Test**  
- 选择延迟低、稳定的节点  
- 晚高峰可切换备用节点

### 6️⃣ 使用流媒体（Netflix / YouTube / Disney+）

- 选择已确认支持当前客户端订阅格式的节点，并验证目标平台能否播放
- 开启 **Rule + 流媒体策略**  
- 实际能否播放取决于节点、账号与平台规则

## ❌ 常见问题与避坑指南

1. **节点无法连接**  
   - 检查订阅链接是否过期  
   - 网络环境是否限制代理

2. **延迟高 / 掉速严重**  
   - 切换节点  
   - 晚高峰可选择备用节点

3. **客户端报错 / 闪退**  
   - 更新到最新版  
   - 清理旧配置后重新导入

4. **低价节点慎用**  
   - 便宜但节点少、无维护体验差  
   - 推荐长期维护、稳定节点

## 🧭 新手节点选择建议

| 场景 | 推荐类型 | 说明 |
|------|----------|------|
| 日常科学上网 | Vmess / SS | 稳定即可 |
| 流媒体解锁 | 流媒体专用节点 | Netflix / Disney+ |
| 预算有限 | 99吧 / Flybit | 先比较短周期价格、流量和试用条件 |
| 长期使用 | 先筛选通用订阅，再验证常用节点 | 全球云通用订阅待核实；专属客户端不能直接套用本教程 |

## 🚀 总结

- **Clash节点 = 科学上网跳板**  
- 新手操作流程：**获取订阅 → 导入Clash → 选择策略 → 测速 → 使用**  
- **稳定性 > 速度 > 价格**，优先保证使用体验

> 导入成功后仍需启用配置和连接。先打开常用网站，再检查流媒体或其他目标平台；延迟数字不能替代实际使用验证。
