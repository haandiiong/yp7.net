## 筛选口径

本页主要整理低预算月付、试用和备用候选。先核对额度、付款周期与客户端；能否承担日常使用，应由自己的常用网络、时段和应用验收决定。

本榜以低预算常规月付为主，不把不可续费的新人优惠当作长期月费。AnDy Cloud月付5元100GB、限2台；年付30元50GB/月须一次支付全年费用，折合2.5元/月不能当作逐月付款价。

[极速Cloud](/posts/jisucloud-review-2026/)新人体验已改为15元200GB，按10倍倍率折合20GB，限2台、只能购买一次且不能续费；常规月付30元起，最低档折合100GB/月，已移出本页低价候选。其他机场的季付或首购季付折合月价，也不代表一个月的实际付款额。

## 同预算下，20GB、100GB和300GB怎么选？

先用机场后台的实际扣量估计下个周期需求，再核对客户端、同时在线设备和节点倍率。下面比较的是已记录的**月付或30天套餐标价**，不含优惠，不代表已核验的首次实付或日后续费金额。没有明确倍率时，不默认按1倍扣量，也不把标称额度直接当作可传输量；年付折合月价和一次性总量包不混进月付预算。

### 约20GB／30天：先比较3元标价与使用限制

- **[阿达西3元20GB／30天](/posts/adaxi-review-2026/)**：适合先比较小额度周期套餐；标注限速100Mbps、设备数不限；Windows新增商家称官方的GBox账号登录，仍提供通用订阅教程，其余平台按第三方文档。不支持免费试用仍据9月27日补充，退款待核实。10月17日充值页默认10元且允许自填3元，未点击确认或验证支付渠道，**10月18日用户确认最低充值支持1元**，默认10元不是充值下限。3元套餐仍需3元账户余额，手续费与实际到账未通过付款验证。
- **[杏花云3元月付、标称200GB／月](/posts/xinghuayun-review-2026/)**：标价同为3元，但限2台设备；已记录通用订阅和Windows Clash Verge教程，其他客户端格式需另确认。不支持免费试用，倍率、具体重置日期与退款规则仍待核实，不能仅凭较大的标称额度判断更合适。
- **[九云6元150GB／月](/posts/jiuyun-review-2026/)**：10月19日现售仍为6元150GB、3台并发；同日读取Clash Verge与Shadowrocket等第三方教程。每30天刷新、无试用和不退款仍据9月22日旧记录，本次卡片未重复。额外流量是否有价值取决于实际扣量，不代表线路表现更好。

### 约100GB／月、标价10元内：先决定是否需要官方客户端或试用

- **[AnDy Cloud 5元100GB／月](/posts/andycloud-review-2026/)**：限2台设备，购买套餐后才开放通用订阅导入；周期流量按每月账单日重置，未用不累积。不支持免费试用，计费倍率和退款条件待核实；30元年付档只有50GB／月，不能当成同一100GB档的低价月付。
- **[xxyun 9.99元100GB／月](/posts/xxyun-review-2026/)**：适合接受官方客户端、不需要通用订阅的用户。10月17日核对无退款政策，提供手机、电脑、所列Linux和x86软路由官方登录路线；不支持Clash、FlClash或Shadowrocket通用订阅，未新注册验证试用。套餐卡片标注不限设备，流量每月订单日重置且不结转，具体系统与架构先确认。

### 约300GB／月、标价6至10元：一起看设备数和周期规则

- **[熊猫cloud 6元300GB／月](/posts/xiongmaocloud-review-2026/)**：限3台设备，提供Clash和Shadowrocket等通用订阅教程；每月订单日重置，未用不累积。不支持免费试用，已核对套餐明确不退款。先核对所用节点的倍率，再判断300GB标称额度是否够用。
- **[九云9元300GB／月](/posts/jiuyun-review-2026/)**：10月19日现售仍为9元300GB、4台并发，第三方客户端订阅；每30天刷新、无试用和不退款仍据9月22日旧记录。不要把6元150GB档的3台限制套到9元档，也不要把季付18元200GB／月当作18元月付。
- **[AnDy Cloud 10元300GB／月](/posts/andycloud-review-2026/)**：限3台设备，付费后取得通用订阅，月度账单日重置；不支持免费试用，倍率、退款及额外重置费用待核实。续费不会立即补量，切换套餐还可能覆盖原套餐，应先确认剩余权益的处理。

九云10月19日新增的19.90元500GB、29.90元1000GB均为一次付款、365天内共用总量，分别限3台和5台；不能把它们当作500GB/月、1000GB/月或永久备用包。同期88元年付400GB/月为4台，按月提供额度，与上述年期限总量包分开比较。8折码 `9yun` 于10月19日读取公告后，用户同日另明确仅19.90元、29.90元两款365天流量包不适用，六款周期商品及36元、99元两款不限时包均可用、不限次数。截止、叠加和结算未核，本页仍按套餐标价比较。

这些取舍仅使用链接详情中的既有商业资料，不是新的速度或稳定性排名。若只是偶尔消耗少量流量、并非每月都有上述用量，再到[不限时套餐比较](/rankings/no-expiry/)核对一次付款金额、总流量、期限及重购规则；不要为了较低每GB单价预付用不完的额度。

## 风险提示

- 价格和标称流量不能证明速度或稳定性，先在常用网络与晚高峰验证实际应用。
- 核对试用、客服、退款、倍率及设备限制；流量额度与使用强度不匹配时，再比较其他档位。
- 依赖网络办公时准备备用方案，并在续费前复核，不因低价或高价就跳过验收。
