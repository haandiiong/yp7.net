“科学上网”“翻墙”“梯子”是日常语境里的说法，常用来指借助代理或VPN改变部分网络请求的访问路径。它们不是一个统一协议，也不表示连接后所有应用都会走同一条线路。

新手先区分三件事：**客户端是设备上的软件，协议决定如何通信，机场是提供节点或订阅的服务商。** 选择哪个服务、使用什么协议和是否需要软路由，是不同层面的决定。

<!-- more -->

## 翻墙、VPN、代理、机场分别是什么

| 名称 | 本文中的含义 | 需要区分的事情 |
| --- | --- | --- |
| 科学上网、翻墙 | 对改变访问路径等做法的通俗称呼 | 不是具体软件、协议或质量等级 |
| 梯子 | 对相关工具或服务的俗称 | 需进一步确认实际客户端和接入方式 |
| VPN | 虚拟专用网络，可通过隧道连接到另一网络或网关 | 有不同协议和用途；消费类服务与单位VPN不能混为一谈 |
| 代理协议 | 客户端与转发节点通信的一组规则，如Shadowsocks、Trojan | 协议名称不能证明服务商速度、安全管理或持续可用性 |
| 客户端 | 登录服务或读取节点配置的软件 | 是否支持某种订阅，要看客户端与服务商的兼容说明 |
| 机场 | 提供代理节点、账号或订阅的服务商 | 是服务交付方式，不是一种加密协议 |
| 软路由 | 用通用硬件及路由软件承担网络转发等功能 | 是否覆盖某台设备或某类流量，取决于实际配置 |

V2Ray是支持多种协议与路由配置的软件平台，不能把“V2Ray”本身理解为一个速度档位。具体能力可查[V2Fly项目说明](https://www.v2fly.org/)。Shadowsocks的本地、远端组件如何转发数据，见其[官方协议介绍](https://shadowsocks.org/doc/what-is-shadowsocks.html)。

## 科学上网的工作原理

以使用远端代理的请求为例，可以先理解成：

```text
目标应用 → 本地客户端 → 远端转发节点 → 目标网站
```

客户端按配置决定请求是直接发送，还是交给远端节点转发。浏览器能使用系统代理，不表示终端、游戏或其他应用也已使用同一代理；判断具体请求时，应查看对应客户端的连接记录、规则命中和应用设置。[MDN代理与隧道说明](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Proxy_servers_and_tunneling)介绍了代理转发与隧道的基本作用。

**转发路径与内容加密需要分别确认。** 客户端到远端节点如何保护数据，取决于实际协议与配置；访问目标网站时的HTTPS是另一层保护。把请求交给中间节点，并不会自动让网站变成HTTPS，也不会消除账号、设备和服务商管理方面的风险。

## 加密保护哪一段，还需要信任谁

| 环节 | 需要确认 | 不能直接推导的结论 |
| --- | --- | --- |
| 设备与客户端 | 下载来源、版本更新、权限和配置 | 安装了代理就能防止恶意软件 |
| 到转发节点的连接 | 实际协议、加密与认证设置 | 协议名字越新，实际线路就越快或永远可用 |
| 服务商与节点 | 谁负责运营，怎样处理账号、付款资料和日志 | “无日志”宣传已被独立验证 |
| 到目标网站的HTTPS连接 | 证书验证正常，不忽略证书警告 | 使用任何代理时都可以放心输入敏感信息 |
| 网站与账号 | 登录账号、权限和目标平台要求 | 换一个出口IP就等于匿名，或账号不再被识别 |

在证书验证正常的HTTPS连接中，TLS保护传输内容的机密性、完整性并验证服务器身份；它不替你判断网站是否可信，也不保护已被控制的终端。技术范围见[MDN的TLS说明](https://developer.mozilla.org/en-US/docs/Web/Security/Defenses/Transport_Layer_Security)。

## VPN、机场订阅和自建服务器怎么选

没有按协议名称划分的“速度冠军”或“安全冠军”。先看要连接的目标、设备支持和维护责任，再决定是否测试某种服务。

| 方式 | 可以先考虑的情况 | 需要承担或核对的事情 |
| --- | --- | --- |
| 单位或学校提供的VPN | 需要访问其内部系统 | 按管理员要求使用，不把它当作任意公网转发服务 |
| 消费类VPN服务 | 希望使用其客户端和售后方式 | 覆盖哪些应用、账号与付款规则、隐私说明、本地连接表现 |
| 机场账号或订阅 | 已确认所需节点、客户端与订阅兼容 | 节点与套餐限制、运营风险、试用和退款条件 |
| 自建服务器 | 愿意维护服务端，且需要自行控制配置 | 云资源费用、更新、凭据保护、路由与故障处理；自建不保证更便宜或更稳定 |

机场与自建都依赖实际线路、设备和维护。节点多不等于目标应用可用，价格低也不等于首次实付少。比较服务资料可从[机场推荐合集](/posts/jichang-tuijian/)和[机场大全](/posts/jichang-heji/)开始，再核对各条资料与测试日期。

## 新手从哪里开始

1. **明确用途和设备。** 是网页、视频、AI工具，还是单位内部系统；电脑、手机分别使用什么系统。
2. **确认接入方式。** 服务是否提供对应系统的官方客户端，或明确支持你使用的通用订阅格式。账号登录和导入订阅是两条不同路径。
3. **先看购买限制。** 核对付款周期、流量重置、节点倍率、设备限制、试用和退款规则，再决定是否购买。
4. **验证实际请求。** 按教程连接后，检查目标应用是否经过预期节点，并完成自己需要的操作。导入成功或客户端显示已连接，只是开始。
5. **在常用时段重复观察。** 按[机场测速方法](/posts/speedtest-vpn/)记录环境和失败现象，再决定是否续费。

这些步骤没有固定的“5分钟可用”承诺。需要Clash等第三方客户端时，可先看[Clash Verge Rev教程](/posts/clash-verge-guide-2026/)；只想账号登录时，先确认服务商客户端是否支持自己的设备。

## 软路由是不是必须

不是。只在一台电脑或手机上使用时，可以先比较设备上的客户端。软路由适合希望集中管理多台设备、分流和网络设置，并愿意处理路由故障的用户；它不会自动提高上游服务的带宽、稳定性或隐私保障。

设置软路由前，应先确认需要代理的设备与应用，以及不应经过代理的本地网络和单位服务。不要把“路由器已连接”视为每个应用都已验证通过。

## 常见问题

### Shadowsocks一定更快，Trojan一定更稳定吗？

不能这样选。协议只是一部分，服务端容量、路由、客户端实现、设备性能与使用时段都需要实际比较。相同协议也可以出现不同结果。

### 免费服务和付费服务，哪个更安全？

价格不能证明安全。两者都要核对运营者、软件下载来源、权限、隐私说明和维护情况；付费也不自动解决日志、终端或账号风险。

### 换了出口IP，就不会被网站识别吗？

不会因此获得匿名保证。登录账号、Cookie等仍可能关联你的使用；目标平台也有自己的访问与账号要求。

### 机场支持AI，就代表ChatGPT、Claude和API都能用吗？

不能。官网说明、客户端兼容和应用测试是三类信息。查看[带日期的ChatGPT记录](/rankings/chatgpt/)时，也要注意这些记录没有自动覆盖其他AI平台或长期使用。
