🧠 什么是Clash节点？

Clash节点就是可以访问国外网络的“跳板”。
通过节点，你的网络请求可以绕过限制，访问被封锁的网站或流媒体。

节点工作原理

  1. 本地设备 → Clash客户端
    Clash在本地充当代理，接收请求。

  2. Clash客户端 → 节点服务器
    节点位于海外，访问目标网站。

  3. 节点服务器 → 本地设备
    返回网站内容；能否连接和访问目标服务仍需实际验证。

💡 小贴士：协议名称和地区标签不能证明节点表现。连接后要用自己的目标应用验证。

📊 Clash节点协议分类

协议说明使用时核对
VMess一种代理协议客户端内核是否支持配置中的传输方式
Shadowsocks / ShadowsocksR不同的代理类型订阅中的类型与加密方式是否受支持
Trojan使用 TLS 的代理协议服务器、端口和 TLS 配置是否完整
Snell / SOCKS5不同的代理类型按服务商说明导入，不能互换类型名称

客户端支持的协议取决于所带内核与版本。新手优先使用服务商提供的兼容订阅，不必先手动改协议；协议名称本身不能证明速度或稳定性。Mihomo 出站代理文档

🚀 新手如何使用Clash节点

1️⃣ 下载Clash客户端

  • Windows / macOS / Linux：Clash Verge Rev 教程 / FlClash 教程
  • Android：FlClash / Clash Meta 教程
  • iOS：先查看 iPhone 客户端安装说明，再核对所选应用的订阅格式；不要直接套用桌面版 Clash 的菜单与配置步骤。

2️⃣ 获取节点订阅

  • 提供兼容订阅的机场（例如：Flybit / 网际快车 / 99吧）。xxyun 仅支持官方客户端，不能用于本节的订阅导入流程。

3️⃣ 导入节点

  1. 打开Clash客户端
  2. 进入 配置文件/Config
  3. 选择 导入远程订阅 或 本地导入
  4. 粘贴订阅链接或选择配置文件
  5. 点击 应用/启用

4️⃣ 选择代理策略

  • Global（全局模式）：进入内核的流量使用全局策略组，需先在该组选择节点
  • Rule（规则模式）：按当前配置的规则决定流量去向
  • Direct（直连模式）：进入内核的流量直接连接

日常可从 Rule 模式开始，但实际分流取决于订阅中的规则。模式选择与系统代理、VPN 或 TUN 的开启是不同设置。Mihomo 运行模式说明

5️⃣ 验证连接与目标应用

  • 客户端的延迟检测用于初筛，不等于下载测速或长期稳定性测试。
  • 打开常用网站，再在客户端连接记录中核对目标请求、命中规则和实际使用的节点。
  • 完成目标应用中的实际操作；浏览器可用不能证明终端或其他App也已走代理。
  • 若只在特定时段异常，记录当时节点、时间、报错，再用相同操作比较。方法见机场测速与验证指南。

6️⃣ 使用流媒体（Netflix / YouTube / Disney+）

  • 选择已确认支持当前客户端订阅格式的节点，并验证目标平台能否播放
  • 按当前配置检查该平台命中的规则和策略组；不是所有订阅都含有名为“流媒体”的策略组
  • 实际能否播放取决于节点、账号与平台规则

❌ 常见问题与避坑指南

  1. 节点无法连接

    • 检查订阅链接是否过期
    • 网络环境是否限制代理

  2. 延迟高 / 掉速严重

    • 切换节点
    • 晚高峰可选择备用节点

  3. 客户端报错 / 闪退

    • 记录版本和错误提示，先按官方说明检查兼容性
    • 保存旧配置后再修改；导入失败按订阅排错步骤定位

  4. 价格不能代替使用验证

    • 核对实际付款周期、流量、设备数、试用与退款条件
    • 没有相应记录时，不根据价格推断维护、速度或稳定性

🚀 总结

  • Clash节点 = 科学上网跳板
  • 新手操作流程：获取兼容订阅 → 导入并启用配置 → 选择策略与节点 → 启动代理 → 验证目标应用
  • 按自己的应用、预算和设备选择；有来源的测试记录与套餐条件分别核对

导入成功后仍需启用配置和连接。先打开常用网站，再检查流媒体或其他目标平台；延迟数字不能替代实际使用验证。
