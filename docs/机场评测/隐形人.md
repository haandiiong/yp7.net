## 客户端下载与使用流程

| 设备 | 官网教程与入口 | 连接方式 |
|---|---|---|
| Android | 仪表盘提供arm64-v8a主下载 | 安装客户端，以官网账号登录后快速连接 |
| Windows | 帮助中心提供自研客户端教程 | 登录账号，更新节点、测试延迟后连接 |
| Mac | 提供Mac客户端及安装教程 | 登录账号，更新节点、测试延迟后连接 |
| iPhone / iPad | App Store安装Nextin，需要可用的外区Apple ID | 输入站点识别码 `yxr`，登录账号并连接 |

1. 从上方官网入口注册或登录，先核对套餐周期、流量及设备限制。
2. 在仪表盘的客户端下载区选择设备，并参考帮助中心对应教程。
3. Android、Windows和Mac使用官网账号登录客户端；iOS在Nextin内填写识别码 `yxr` 后登录。
4. 更新节点、测试延迟，选择节点后启用连接，首次使用按系统提示授予VPN配置权限。
5. 验证自己的常用网站和应用，再决定是否适合长期使用。

隐形人不支持通用订阅，不能导入Clash、FlClash或Shadowrocket使用。需要通用订阅的用户可继续比较[Clash机场分类](/rankings/clash/)。
