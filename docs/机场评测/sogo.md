## sogo客户端下载与使用流程

控制台提供四个平台的客户端入口，帮助中心对应4篇客户端教程。

| 设备 | 本次确认的入口 | 使用方式 |
|---|---|---|
| Android | 两种架构的安卓安装包 | 下载与设备匹配的安装包，在客户端登录官网账号 |
| Windows | Windows客户端 | 安装后登录官网账号 |
| macOS | Mac客户端 | 安装后登录官网账号 |
| iPhone / iPad | iOS教程使用Nextin | 使用外区Apple ID下载，填写识别码后登录官网账号 |

首次使用可按以下流程操作：

1. 通过上方官网入口注册或登录，查看当前套餐和账户权限。
2. 在控制台选择对应系统的客户端下载入口，按帮助中心教程安装。
3. iOS用户按教程下载Nextin，填写客户端识别码 **sogoyun**，再使用官网注册的账号登录。这个识别码用于客户端识别服务。
4. 在客户端查看节点并连接，检查常用网页、视频或工作应用能否正常使用。

**sogo不支持通用订阅**，需使用官方客户端或iOS Nextin，通过官网账号登录。需要在Clash、FlClash或软路由中导入订阅的用户可查看[Clash机场榜](/rankings/clash/)。
