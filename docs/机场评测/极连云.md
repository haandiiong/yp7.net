## 套餐价格与流量

| 套餐 | 价格 | 流量 |
|---|---|---|
| 限时年付套餐体验 | 96元/年 | 60GB/月 |
| 基础套餐 | 18元/月 | 100GB/月 |
| 进阶套餐 | 32元/月 | 200GB/月 |
| 旗舰套餐 | 61元/月 | 500GB/月 |
| 尊享套餐 | 122元/月 | 正文1000GB/月，卡片1.0TB |
| 不限时套餐 | 卡片399元/一次性，正文680元（冲突） | 总计600GB |

周期套餐标注季付以上从购买日起每30天刷新流量；96元年付套餐是60GB/月。套餐均标注1倍率、不限制同时使用客户端数量，并宣传IPLC及最高2.5Gbps，实际速度和解锁能力需要自行验证。

### 不限时价格存在冲突

不限时包卡片为399元600GB，正文却写售价680元；重置说明写“原价90%”，并同时写612元和“399×0.9”，计算关系不一致。因此本文不确认其最终售价或重置费用，购买前需客服澄清。

该包为一次性总流量，不自动按周期刷新，也不参加周期套餐长期折扣。普通套餐宣传一年8折、两年7折、三年6折，实际金额以下单页为准；旧8折码 `JLY888` 本次未验证。

## 客户端与订阅方式

仪表盘有Android、iOS、macOS、Windows下载区；知识库另有Linux和软路由分类。Windows教程明确提供极连云客户端，使用注册邮箱登录，更新节点、测试延迟后连接。

仪表盘同时出现第三方软件推荐及订阅导入提示，但本次未见实际订阅领取入口，通用订阅支持条件暂列待核实，不能根据推荐文字推断已经开放。

1. 从上方官网入口登录，选择合适套餐。
2. 查看系统对应知识库教程，下载客户端并登录。
3. 更新节点、测试延迟，选择节点并连接。
4. 如需要第三方订阅，购买前向客服确认套餐和领取条件。

## 使用限制与购买建议

- 所见套餐均明确不接受退款。
- 96元年付套餐特别提示福建、新疆不保证可用；相关地区应先确认支持情况。
- 免费试用条件本次未见明确说明，暂列待核实。
- 月付适合先核对设备和日常使用；不限时包应先解决价格冲突再考虑购买。
- 原生IP、流媒体、ChatGPT与TikTok解锁是商家说明，不作为本站实测结论。
